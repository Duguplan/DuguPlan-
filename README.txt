# StudyTrack Starter
Open `index.html` in a browser.

Included:
- UPSC, BPSC TRE 4.0, CUET UG sections
- Subject-wise classes
- Completion percentage
- Beginner/Basic/Intermediate/Advanced/Exam Ready level
- Add custom classes
- Attach a local resource filename to a selected class
- Browser localStorage persistence

For a full online version with login, real PDF/video uploads, cloud database, and a shareable public URL, connect Firebase (Auth + Firestore + Storage) and deploy the app.
